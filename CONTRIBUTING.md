# Contributing to Renom

Thanks for helping make Renom better. The source code is not published in this repo, so contributions here are bug reports, ideas and documentation improvements.

## How to Contribute

1. **Report a bug.** Open an issue and describe what you did, what you expected, and what happened instead. Add the Renom version (2.1) and your Windows version.
2. **Suggest a feature.** Open an issue and explain the problem it solves and how you would use it.
3. **Improve the docs.** Open an issue describing the change, or a pull request with the corrected text. Small fixes (typos, unclear steps, missing examples) are welcome.

## Reporting Bugs Well

A good bug report includes:

- The Renom version and whether you used Setup or Portable
- What you clicked, in order, and what the files were named before
- What you expected vs. what actually happened
- A screenshot if it helps

## Code of Conduct

Be kind and respectful. No spam, no self-promotion, no unrelated links.
