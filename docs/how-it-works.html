File Selection & Grouping Logic

Renom does not always treat every file as completely separate.

If multiple files share the same base name, Renom treats them as one group and applies the same change to all of them. The extension stays unchanged. As long as the main name is the same, the same change is applied. The file base name is the part before the extension.

Logo design.eps Logo design.jpg
Both files share the same base name: Logo design.
So the same change is applied to both files.
Package design.eps client_Brief.txt
These files have different base names: Package design and client_Brief.
So they are treated separately.
Original Files → Grouping
Original File Names
Logo design.eps
Logo design.jpg
Package design.eps
client_Brief.txt
Grouped Result
Group 1: "Logo design"
Logo design.eps
Logo design.jpg
Group 2: "Package design"
Package design.eps
Group 3: "client_Brief"
client_Brief.txt
Important Points
  • You can click Preview to see the result before applying changes.
  • If something is applied by mistake, click Undo Last Action to restore the previous state.
  • The affected files remain selected, so you don't need to select them again. But if you select new file(s), the previously selected files will be deselected and only the new files will remain selected.
  • You can select files or folders using Drag & Drop.
  • When a folder is selected, files inside its subfolders are included automatically.
  • When an IF option is selected, a sample value appears in the placeholder to help you understand what to enter. IF option → placeholder example → what to type clear
File Name Format
Decide how the new file name will be created. Examples help you see the result in advance.
Leave blank

If the File Name Format field is left empty, Renom removes the old file name and replaces it with automatic numbering based on your starting number (by default 01).

Original Files
Invoice.pdf Receipt.pdf Report.pdf
Format
[Leave Blank]
Starting Number: 01
Result
01.pdf 02.pdf 03.pdf
Note: Only the file name changes. The extension stays unchanged.
Fill the Existing Format gap

Renom looks at file names that already have numbers in them, finds any missing number in the sequence, and then renames the files to close that gap. The format is listed in the app's File Name Format options, and the cheatsheet example shows it as turning File 01, File 03 into File 01, File 02

Before
File 01.txt File 03.txt File 05.txt
After
File 01.txt File 02.txt ← was 03 File 03.txt ← was 05
Note: This works only when the selected file names already contain numbers.
{original} Your Custom Text

Keeps the original file name and adds your custom text after it.

Original File
Report.pdf
Format
{original} Final
"Final" is the custom text
Result
Report Final.pdf
Note: The original name stays. Your text is simply added to it.
{original} {date}

This format keeps the original file name and adds the current date after it.

Original File
Backup.zip
Format
{original} {date}
Date format: DD-MM-YYYY
Result
Backup 30-03-2026.zip
{original} {time}

This format keeps the original file name and adds the current time after it.

Original File
Screenshot.png
Format
{original} {time}
Time format: HH-MM-SS
Result
Screenshot 14-30-52.png
Your Custom Text {date}

This format replaces the old file name with your custom text, adds the current date, and then adds sequence numbering automatically.

Original File
IMG_8930.jpg
Format
Trip Photo {date}
"Trip Photo" is the custom text.
Result
Trip Photo 30-03-2026 01.jpg
Note: Because the original name is not used here, Renom adds numbering to keep file names unique.
{original} {datetime}

This format keeps the original file name and adds both date and time after it.

Original File
Export.mp4
Format
{original} {datetime}
Date and time will be added together.
Result
Export 2026-03-30_14-30-52.mp4
Your Custom Text {time}

This format replaces the old file name with your custom text, adds the current time, and then adds sequence numbering automatically.

Original File
Audio.wav
Format
Session {time}
Replace "Session" with your own text.
Result
Session 14-30-52 01.wav
Note: Numbering is added because the original file name is not being kept.
{original}

This format keeps the original file name exactly as it is.

Original File
Photo.jpg
Format
{original}
Result
Photo.jpg
Note: This option does not add anything. It only preserves the original name.
{folder name}

This format uses the name of the folder as the new file name. Since the original file name is not kept, Renom also adds automatic numbering.

Original File
Logo.png Folder: Brand
Format
{folder name}
Result
Brand 01.png
Note: This is useful when files need to be renamed based on their parent folder.
Custom Text {created} / {modified}

These formats use your custom text together with the file's actual created date or modified date as the new file name. Since the original file name is replaced, Renom automatically keeps the file extension.

Original File
Invoice.pdf Created: 15-01-2023 Modified: 30-03-2026
Format
Backup_{created}
Backup_{modified}
Result
Backup_15-01-2023 01.pdf Backup_30-03-2026 01.pdf
Note: The original file name is removed. Your custom text stays, and Renom inserts either the file's created date or modified date. Numbering is added automatically.
Find & Replace
Change specific parts of the file name.
Find chooses the part of the name to modify. Replace determines how that part is updated.
Find old text → replaced → New filename
Group 1: Text Matching
Custom Text

Finds the exact word you type. It does not care about capital letters — searching for 'draft' will successfully find 'DRAFT'.

File name: Invoice Draft.pdf Find: draft Replace: Final Result: Invoice Final.pdf
*Custom Text

Finds the exact word, but capital letters MUST match perfectly. Searching for '*Final' will not find 'final'.

File name: Invoice Final.pdf Find: *Final Replace: Sent Result: Invoice Sent.pdf
Group 2: Symbols & Spacing
- (Hyphen)

Finds dashes (-). Good for removing them or changing them into clean spaces.

File name: Logo-v2-Final.png Find: - Replace: Space Result: Logo v2 Final.png
_ (Underscore)

Finds underscores (_). Good for changing them into spaces to make names easier to read.

File name: Invoice_2024.pdf Find: _ Replace: - Result: Invoice-2024.pdf
space

Finds single spaces. Good for converting them into dashes or underscores for web uploads.

File name: My Photo.jpg Find: space Replace: _ Result: My_Photo.jpg
Duplicate Space

Finds mistakes where two or three spaces are accidentally typed together.

File name: Photo  Album.jpg Find: Duplicate Space Replace: Space Result: Photo Album.jpg
Special Characters

Finds symbols like @, #, $, or %. Good for instantly cleaning up messy downloaded names.

File name: Invoice@#.pdf Find: Special Characters Replace: [Leave Blank] Result: Invoice.pdf
Group 3: Brackets
Inside ()

Finds round brackets AND everything written inside them, treating them as one block.

File name: Logo (Draft).png Find: Inside () Replace: [Leave Blank] Result: Logo.png
Inside []

Finds square brackets AND everything written inside them.

File name: Report [Final].pdf Find: Inside [] Replace: [Leave Blank] Result: Report.pdf
Inside {}

Finds curly brackets AND everything written inside them.

File name: Config {v2}.json Find: Inside {} Replace: [Leave Blank] Result: Config.json
number ()

Finds round brackets ONLY if there is a number inside. Safely ignores text like (Draft).

File name: Photo (25).jpg Find: number () Replace: [Leave Blank] Result: Photo.jpg
Group 4: Position-Based Extraction
First Word

Finds the very first word in the name.

File name: Invoice 2024 Final.pdf Find: First Word Replace: Receipt Result: Receipt 2024 Final.pdf
Last Word

Finds the very last word before the file extension.

File name: Invoice 2024 Draft.pdf Find: Last Word Replace: Complete Result: Invoice 2024 Complete.pdf
First n Words

Finds a specific number of words counting from the start.

File name: Invoice 2024 Final.pdf Find: First 2 words Replace: Document Result: Document Final.pdf
Last n Words

Finds a specific number of words counting backwards from the end.

File name: Project 2024 Final.pdf Find: Last 2 words Replace: Archive Result: Project Archive.pdf
Nth Word from Start

Finds one specific word counting from the start.

File name: Invoice 2024 Final Draft.pdf Find: 3rd word Replace: Review Result: Invoice 2024 Review Draft.pdf
Nth Word from Last

Finds one specific word counting backwards from the end.

File name: Invoice 2024 Final Draft.pdf Find: 2nd word from last Replace: Sent Result: Invoice 2024 Sent Draft.pdf
Group 5: Anchor-Based Search
Text before:

Finds all the text before a specific word you choose, stopping exactly at that word.

File name: Inv 2024 Final Design.pdf Find: Text before: design Replace: Client Result: Client Design.pdf
Text after:

Finds all the text after a specific word you choose, stopping at the file extension.

File name: Invoice 2024 Final.pdf Find: Text after: invoice Replace: Sent Result: Invoice Sent.pdf
Text between:

Finds the text trapped between two specific anchor words you set.

File name: Invoice 2024 Final Draft.pdf Find: between: invoice, draft Replace: Sent Result: Invoice Sent Draft.pdf
Group 6: Multiple Selectors
Item1, Item2, Item3

Finds multiple things at the same time. Just put a comma between them.

File name: Draft - Final / Backup.pdf Find: draft, -, / Replace: [Leave Blank] Result: Final Backup.pdf
Pro Tip: Multi-Find Strategy

Use commas to clean up messy filenames in one single pass. Find all the garbage chunks at once and leave Replace blank to delete them all seamlessly.

Find: draft, copy, (1), -, _ Replace: [Leave Blank] Result: Photo.jpg (clean!)

IF THEN
Choose which files should be selected and what should happen to them.
IF selects the matching files. THEN decides the action applied to those files.

IF Logic

These rules decide which files get selected first. Open any card to see easy examples, exactly what part is matched, and what Renom will include or ignore.

IF
Any File Type(s)
Use , to match any file type from your list.

If a file has one of those extensions, it can be selected. No need for all of them to exist together.

Example Filenames
logo design.eps
banner.jpg
notes.txt
Type in IF
jpg, png, eps
Easy way to remember:
, means this OR that OR that
What Renom Selects
Selected: logo design.eps
Selected: banner.jpg
Ignored: notes.txt
IF
All Common File Types
Use + to require multiple file types in the same name group.

Renom will only select the group if all of those file types exist together. If even one of them is missing, that group will be skipped.

Example Filenames
GROUP 1 (Complete)
logo design 1.eps
logo design 1.jpg
logo design 1.png
GROUP 2 (Missing .png)
logo design 2.eps
logo design 2.jpg
Type in IF
eps+jpg+png
Easy way to remember:
+ means all of these together
What Renom Selects
Group 1: Selected
Group 2: Skipped entirely
IF
Exclude from Common
First check the full set exists, then ignore what you do not want.

The group must contain all required files (like .eps, .jpg, and .png), but Renom will skip the one you minus (like .jpg). Only the remaining matching files will be processed.

Example Filenames
logo design 1.eps
logo design 1.jpg
logo design 1.png
Type in IF
eps+jpg+png-jpg
Easy way to remember:
Build the full set first, then remove what you do not want
What Renom Selects
Selected: logo design 1.eps
Selected: logo design 1.png
Skipped: logo design 1.jpg
IF
Containing Custom Text
Select files whose name contains your typed word anywhere

This rule checks the filename itself, not the extension set. It looks inside the name and selects files that contain your text anywhere in the stem. The current code compares in lowercase, so it is case-insensitive. That means logo, Logo, and LOGO are treated the same for matching.

Example Filenames
Logo Concept.ai
Client Logo Final.pdf
Brand logo preview.jpg
Invoice March.pdf
Poster Design.png
Meeting Notes.txt
Type in IF
logo
Renom will select files whose name contains this word anywhere.
What Renom Selects
Selected: Logo Concept.ai
Selected: Client Logo Final.pdf
Selected: Brand logo preview.jpg
Ignored: Invoice March.pdf
Ignored: Poster Design.png
Ignored: Meeting Notes.txt
Simple meaning: pick files whose names contain this keyword.
IF
Prefix
Select files whose names start with your typed text.

Prefix checks only the beginning of the filename stem. If the name starts with the text you type, it is selected. The code checks in lowercase, so this rule is not sensitive to letter case.

Example Filenames
IMG_001.jpg
IMG_Cover.png
My_IMG_001.jpg
Type in IF
IMG_
Only the very beginning of the name is checked.
What Renom Selects
Matches: IMG_001.jpg
Matches: IMG_Cover.png
Does not match: My_IMG_001.jpg
IF
Suffix
Select files whose names end with your typed text

Suffix checks only the end of the filename stem, just before the extension. If the name ends with your typed text, the file is selected. If that text appears in the middle or at the beginning, it does not count as a suffix match.

Example Filenames
Poster Final.pdf
Logo Black Final.ai
Billboard Final.jpg
Final Poster Mockup.png
Final Delivery Notes.txt
Poster Final Backup.psd
Type in IF
Final
The word must be at the end of the filename stem to match.
What Renom Selects
Selected: Poster Final.pdf
Selected: Logo Black Final.ai
Selected: Billboard Final.jpg
Ignored: Final Poster Mockup.png
Ignored: Final Delivery Notes.txt
Ignored: Poster Final Backup.psd
Simple meaning: pick files that end with this text.

THEN Actions

After IF selects the files, THEN decides what Renom will do. Open each card to see what happens in plain language and with clear examples.

THEN
Rename
Build a new filename and keep the file in the current location

Rename changes only the name. The file stays in the same folder. Renom first builds the new name from File Name Format, Find, Replace, numbering, date/time tokens, and case conversion. Then it renames the file in place.

Examples
Report Draft.pdf → Report Final.pdf
IMG_0021.jpg → Trip Photo 01.jpg
Logo.ai → Client Logo.ai
Backup.zip → Backup 30-03-2026.zip
What Happens
Name changes only
Folder location stays the same. Only the filename is updated.
Easy idea
Use this when you simply want cleaner or more useful names.
Remember: if the file name would become the same as before, Renom may leave it unchanged.
THEN
Delete
Permanently remove the selected files

Delete removes the selected files completely. This is not a rename. It is not a move to another folder. In the current app logic, delete is treated as permanent and it is not fully undoable.

Examples
draft_logo.jpg → deleted
temp_note.txt → deleted
old_mockup.png → deleted
What Happens
Permanent remove
Selected files are deleted from disk after confirmation.
Easy idea
Use only when you are sure those files are no longer needed.
Important: this action is destructive.
THEN
Delete Text
Remove specific text from the filename only

Delete Text does not delete the file. It deletes text from the filename. The app tries to use the IF text first when appropriate, otherwise it can use Find text. After removing that text, it cleans extra separators and spaces, then renames the file.

Examples
Invoice DRAFT.pdf → Invoice.pdf
Logo Copy.ai → Logo.ai
Trip RAW Photo.jpg → Trip Photo.jpg
Poster FINAL FINAL.png → Poster.png
What Happens
Text removed
Only the typed text is removed from the filename. The file itself stays.
Easy idea
Useful for deleting words like draft, copy, temp, final, old, test, or raw from names.
Simple difference: Delete removes the file. Delete Text removes text from the filename.
THEN
Only Keep These File Types
Keep only the requested file types and delete the rest

This action works with file-type style IF input. Renom reads the extension list, keeps matching files, and deletes the rest. So it acts like a cleanup filter for mixed folders.

Examples
Keep: jpg, png → remove ai, pdf, txt
Keep: eps+pdf → remove jpg, svg, docx
Keep: mp4 → remove mov, wav, txt
What Happens
Keep selected types only
Matching files remain. Non-matching files are deleted after confirmation.
Easy idea
Useful when you want only the wanted output types left.
Important: the non-matching files are deleted, not moved aside.
THEN
Copy
Copy selected files to another folder without renaming them

Copy creates a duplicate in the destination folder. In the current code, plain Copy keeps the original filename. It does not apply the new formatted name. This is why Copy is different from Rename & Copy.

Examples
Logo.ai → Archive/Logo.ai
Cover.jpg → Delivery/Cover.jpg
Invoice.pdf → Backup/Invoice.pdf
What Happens
Duplicate created
Original stays where it is. A copy is created in the chosen destination folder.
Easy idea
Use this when you need another copy but want to keep the original file exactly as it is.
Important: plain Copy does not rename in your app logic.
THEN
Move
Move selected files to another folder without renaming them

Move sends the selected file to a destination folder. In the current code, plain Move keeps the old filename. The source folder no longer keeps that file because it has been moved away.

Examples
Logo.ai → Done/Logo.ai
Mockup.jpg → Review/Mockup.jpg
Invoice.pdf → Sent/Invoice.pdf
What Happens
Location changes only
The file is removed from the old folder and placed into the destination folder.
Easy idea
Use this when the file name is already fine and only the folder should change.
Important: plain Move does not rename in your app logic.
THEN
Rename & Copy
Copy to another folder using the new formatted name

This action first builds the new filename from your format and find/replace logic, then copies the file to the destination folder using that new name. The original file remains in place with its current name.

Examples
IMG_0012.jpg → Delivery/Trip Photo 01.jpg
draft_logo.ai → Archive/Logo Final.ai
Audio.wav → Sessions/Session 14-30-52 01.wav
What Happens
Copy + new name
The original file stays. The copied file gets the newly formatted name.
Easy idea
Use this when you want a delivered copy with a clean name but also want to keep your original untouched.
Difference from Copy: this one copies with the new formatted name.
THEN
Rename & Move
Move to another folder using the new formatted name

Rename & Move first builds the new filename, then moves the file to the chosen destination folder with that new name. So both the location and the filename change together.

Examples
IMG_0043.jpg → Final Selects/Trip 01.jpg
draft_menu.pdf → Approved/Menu Final.pdf
Logo Concept.ai → Client Files/Client Logo.ai
What Happens
Move + new name
The source folder loses the file. The destination folder receives the file with its new formatted name.
Easy idea
Use this when you want the file fully finished and placed into its final folder in one step.
Difference from Move: this one also renames while moving.
THEN
Create Group Folder
Make one folder for the selected group and move matching files into it

This action works with the group-based IF rules. Renom creates one destination folder for the matched group, then moves the selected files into that folder. It can also rename the moved files according to the current formatting logic.

Examples
Logo.eps + Logo.jpg + Logo.pdf → folder "Logo"
Poster.ai + Poster.jpg → folder "Poster"
BrandKit.eps + BrandKit.pdf → folder "BrandKit"
What Happens
One folder per matched group
Renom creates the folder in the chosen destination and moves the selected group files into it.
Easy idea
Useful when related files should live together in one folder.
Important: this is intended for group-style IF logic such as All Common File Types or Exclude from Common.
THEN
Zip
Create one zip archive and remove the originals

Zip gathers the selected files and packs them into one zip file. In the current app logic, the originals are then deleted after the zip is created successfully. The zip file is usually named from the group stem.

Examples
Logo.eps + Logo.jpg + Logo.pdf → Logo.zip
Poster.ai + Poster.jpg → Poster.zip
Audio.wav + Audio.mp3 → Audio.zip
What Happens
Create zip + delete originals
After zipping, the original files are removed from their old location.
Easy idea
Useful when you want one compact package instead of many separate files.
Important: this also removes the original loose files.
THEN
Copy & Zip
Create one zip archive but keep the original files

Copy & Zip creates a zip archive from the selected files, but unlike plain Zip, it does not delete the original files. So you end up with both the original files and the new zip package.

Examples
Invoice.pdf + Receipt.pdf → Documents.zip
Logo.eps + Logo.jpg → Logo.zip
Slides.pptx + Notes.txt → Meeting.zip
What Happens
Create zip + keep originals
The originals stay where they are. A zip file is created as an extra output.
Easy idea
Use this when you need a zip but do not want to lose the source files.
Difference from Zip: originals stay untouched.
THEN
Move & Zip
Create one zip archive and remove the originals after packing

Move & Zip also creates one zip archive, and the originals are removed after the archive is created. In the current code, the zip itself can be placed in a chosen destination folder, so it is useful when the final archive should live elsewhere.

Examples
Project Files → Delivery/Project.zip
Logo Set → Archive/Logo.zip
Source Pack → Client/Source Pack.zip
What Happens
Create zip + remove originals
The archive becomes the final kept output. The original unpacked files are removed.
Easy idea
Useful when your final deliverable should be one zip file in another folder.
Think of it as: keep the packed version, not the loose files.
THEN
Move & Delete
Move matching files and permanently delete the rest

Move & Delete is a split action. Files that match the IF rule are moved to the chosen destination. Files that do not match are permanently deleted. So this action is used like a strong filter: keep the important set, destroy the rest.

Examples
Keep jpg → move jpg, delete png/pdf/txt
Keep mp4 → move mp4, delete wav/srt/jpg
Keep eps+pdf → move those, delete others
What Happens
Move matches + delete non-matches
Matching files are kept by moving them. Non-matching files are removed permanently.
Easy idea
Use this only when you are sure you want to keep a very specific set and remove the rest.
Important: unmatched files are deleted.
